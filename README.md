# Snoop

A native Android glance interface for live activity, media, notifications, and useful system events.

Snoop is being developed as an independent implementation using Android's public SDKs and documentation. Its architecture, source code, UI, assets, and product identity are original to this project.

## Project status

Early foundation. The current commit establishes the Android app scaffold and visual starting point. Overlay behaviour and system integrations are not implemented yet.

## Development

Open the project in the latest stable Android Studio, allow Gradle sync, then run the `app` configuration on an Android device or emulator.

- Language: Kotlin
- UI: Jetpack Compose
- Minimum Android version: Android 8.0 (API 26)
- Application ID: `com.harry12132.snoop`

## Principles

- Native Android APIs, with explicit and minimal permissions.
- Clear privacy explanations and user-controlled features.
- Responsive, restrained UI and purposeful motion.
- Testable components and documented platform limitations.
